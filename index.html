CASE 07

Four-Arm Collaborative Recycling Sorting on a Wood-Chip Stream

木屑流からの資源回収 — 4アーム協調ソーティング

Client engagement: build a solution that detects and picks recyclable objects (glass, metal, solid wood) out of a moving wood-chip stream. The proposed architecture combines VLA-based perception with multi-arm collaboration coordinated by a master scheduling policy: a shared global target pool, intercept prediction, cost-based dynamic assignment and reassignment, and collision-aware parallel execution across four identical arms. The 24-second storyboarded demo (Isaac Lab) visualizes the scheduler making assignment decisions live, including workload balancing, a mid-task reservation transfer to a downstream arm, and simultaneous picks.

顧客案件:流動する木屑ストリームからガラス・金属・木材などのリサイクル対象を認識・把持するソリューション。VLAベースの認識と、マスター方策による多腕協調(共有ターゲットプール/迎撃予測/コストベースの動的割当・再割当/衝突回避並列実行)を組み合わせた構成です。24秒のデモ(Isaac Lab)では負荷分散、下流アームへの予約移譲、同時ピックなどスケジューラの意思決定を可視化しています。

CASE 01

OpenArm Pick-and-Place in NVIDIA Isaac — RL to Sim-to-Real

OpenArm ピッキング(NVIDIA Isaac)— RLからSim-to-Realへ

Company R&D assignment: evaluate the OpenArm open-source robot arm project. Using open assets in the NVIDIA Isaac environment, I trained grasping policies with reinforcement learning and reached stable, repeatable picks; the resulting policy can be deployed directly onto the physical unit for sim-to-real transfer.

社内R&Dタスク:オープンソースの OpenArm プロジェクトの評価。NVIDIA Isaac 環境でオープンアセットを用いてRLで把持方策を学習し、安定したピッキングを実現。得られた方策は実機へ直接展開して Sim-to-Real が可能です。

CASE 02

High-Speed Driving on Snow — DEM Snow Simulation

雪道高速走行 — DEMによる雪のシミュレーション

Client engagement: develop an API that reproduces Rocky-DEM-class capability to simulate vehicles driving at high speed on snow. The snow in this video is fully DEM-based (discrete element method). The scenario evaluates forward visibility degradation and sensor-risk under snow spray thrown up by the vehicle.

顧客案件:Rocky DEM 相当の機能を再現するAPIを開発し、雪道での高速走行を仿真。映像中の雪はすべてDEM(離散要素法)で実装。巻き上げられた雪による前方視界の劣化とセンサーリスクを評価します。

CASE 03

Agricultural Drone Spraying — SPH Coverage Prototype

農業ドローン散布 — SPHによる被覆率プロトタイプ

顧客案件:ドローン農薬散布と被覆率テストのプロトタイプ開発。噴霧はSPH(平滑粒子流体力学)で実装し、圃場の被覆率とドリフトを評価しています。

CASE 04

Genesis Drone Simulation Capability Assessment

Genesis ドローンシミュレーション適性評価

Client engagement: assess whether the open-source Genesis engine can carry drone-simulation workloads. I ran a structured evaluation from basic function tests through RL and sim-to-real oriented robustness: direct API motor control, interactive flight, autonomous waypoint flight, an RL training environment with parallel policy learning, before/after policy comparison, disturbance stress tests, and a customer inspection mission.

顧客案件:オープンソースのGenesisがドローン仿真シナリオを担えるかの適性評価。API直下のモータ制御から、対話操縦、自動飛行、並列RL学習、学習前後比較、外乱ロバスト性、顧客の巡検ミッションまで段階的に検証しました(基本機能テスト+Sim-to-Real+RL)。
